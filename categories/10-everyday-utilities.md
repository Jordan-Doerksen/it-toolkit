# 10 — Everyday Utilities

The little tools that end up on basically every machine you touch.

| Tool | What it does | Platform | License |
|------|--------------|----------|---------|
| **[7-Zip](https://www.7-zip.org/)** | The archive tool. Opens/creates zip, 7z, rar, tar, iso, and everything else. Free, no nag. | Win | **OSS** |
| **[Everything](https://www.voidtools.com/)** (voidtools) | Instant filename search across your whole drive — results as you type. Once installed you stop using Windows Search. | Win | Free |
| **[Microsoft PowerToys](https://learn.microsoft.com/windows/powertoys/)** | A whole pack: FancyZones window tiling, PowerRename bulk rename, a Spotlight-style launcher, color picker, always-on-top, and more. | Win | **OSS** |
| **[Greenshot](https://getgreenshot.org/)** / **[ShareX](https://getsharex.com/)** | Screenshot + annotate. ShareX also does screen recording, GIFs, and auto-upload. ShareX is the power option. | Win | **OSS** |
| **[Notepad++](https://notepad-plus-plus.org/)** | Fast text/code editor with syntax highlighting. (Also in Editors category.) | Win | **OSS** |
| **[Bulk Rename Utility](https://www.bulkrenameutility.co.uk/)** | Rename hundreds of files with rules. (PowerToys PowerRename is the lighter alternative.) | Win | Free |
| **[Ninite](https://ninite.com/)** | Tick a bunch of apps, get one installer that installs/updates them all silently — no toolbars. Fastest way to set up a fresh PC. | Win | Free |
| **[Chocolatey](https://chocolatey.org/)** / **[winget](https://learn.microsoft.com/windows/package-manager/)** | Command-line package managers for Windows — install/update software with one command. winget ships with Windows now. ●● medium. | Win | OSS / Free |
| **[QuickLook](https://github.com/QL-Win/QuickLook)** | Hit spacebar to preview any file (like macOS). Small quality-of-life win. | Win | **OSS** |
| **[Zoom It / Carnac](https://learn.microsoft.com/sysinternals/downloads/zoomit)** | Screen zoom + annotation for demos and showing a client something. | Win | Free |
| **[HWiNFO / CrystalDiskInfo](03-system-info-hardware.md)** | Live on almost every tech's USB stick — see the Hardware category. | Win | Free/OSS |

**Rule of thumb:** New machine setup → Ninite (or winget) to bulk-install. Daily drivers → 7-Zip + Everything + PowerToys + a screenshot tool. These four alone make any Windows box nicer to work on.
