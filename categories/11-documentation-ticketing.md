# 11 — Documentation & Ticketing

Write things down, draw the network, track tickets and assets. The boring stuff that saves you at 2 a.m.

| Tool | What it does | Platform | License |
|------|--------------|----------|---------|
| **[draw.io / diagrams.net](https://www.drawio.com/)** | Free diagramming for network maps, rack layouts, flowcharts. Runs in-browser or as a desktop app; files are plain XML. | Web / Win / macOS / Linux | **OSS** |
| **[Joplin](https://joplinapp.org/)** | Open-source note-taking with Markdown, sync, and encryption. Great personal/tech knowledge base. | Win / macOS / Linux / mobile | **OSS** |
| **[Obsidian](https://obsidian.md/)** | Markdown notes on local files with powerful linking. Free for personal use. Popular for runbooks/KBs. | Win / macOS / Linux / mobile | Free (personal) |
| **[BookStack](https://www.bookstackapp.com/)** | Self-hosted wiki organized as books/chapters/pages. Ideal shared IT documentation platform. ●● medium. | Self-host / web | **OSS** |
| **[osTicket](https://osticket.com/)** | Classic self-hosted help-desk / ticketing system. Free and proven. ●● medium. | Self-host / web | **OSS** |
| **[GLPI](https://glpi-project.org/)** | Self-hosted IT service management: tickets **plus** full asset inventory (with the GLPI agent). Punches above free-tier weight. ●● medium. | Self-host / web | **OSS** |
| **[Snipe-IT](https://snipeitapp.com/)** | Purpose-built IT **asset management** — track laptops, licenses, who has what, warranties. Excellent and free. ●● medium. | Self-host / web | **OSS** |
| **[NetBox](https://netboxlabs.com/community/)** | Source-of-truth for network/infrastructure (IPs, VLANs, racks, cabling). Upper end of medium. ●● medium. | Self-host / web | **OSS** |
| **[IT-Tools](https://it-tools.tech/)** | A single web page of handy converters/generators (hashes, base64, subnet calc, UUIDs, cron, JWT…). Self-hostable. Bookmark it. | Web / self-host | **OSS** |

**Rule of thumb:** Draw the network → draw.io. Personal runbook → Joplin/Obsidian. Team wiki → BookStack. Tickets → osTicket, or GLPI if you also want asset tracking. Just track hardware/licenses → Snipe-IT.
